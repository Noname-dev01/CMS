# CLAUDE.md — com.cms.common.html

- **콘텐츠 본문은 HTML이다**(2026-10-07, `adversarial-review/plan/PLAN-html-editor.md`): 관리 화면은 Quill 2.0.3 편집기(`/vendor/quill/`, `static/js/admin/notice-editor.js`), 서버는 `common/html/HtmlContentSanitizer`(jsoup 1.23.2 허용 목록 — `p br strong em u s h2 h3 ol ul li blockquote a img`, 링크는 http/https/mailto와 **루트 상대 내부 링크**(`common/web/InternalLinkPaths` — `/` 시작·경로에 `%`·`;` 없음·비공개 경로 아님(`PrivatePaths`, `SiteLinkPolicy`와 공유)·숫자 게시판 경로 아님(`BoardLinkPaths` — 공개 게시판 주소는 슬러그만, 2026-10-28 PR 4a), 위반은 `href`만 제거, 내부 링크는 `target` 없이 같은 창 — 2026-10-28 PR L, 전·후처리는 `data-il` 표지 속성으로 Cleaner를 우회), 이미지는 `/content-images/{id}`만)로 **저장 시와 출력 시 모두** 정리한다(멱등). 본문을 출력하는 새 경로·새 콘텐츠 도메인은 반드시 이 sanitizer를 거치고(이미지를 지원하지 않는 콘텐츠는 `sanitize(html, false)`/`ContentBodyPolicy.sanitizePage` — 정적 페이지가 첫 사례), 편집기 `formats`·툴바·sanitizer 허용 목록을 1:1로 맞춘다. 저장 형식의 공백은 "연속 공백의 첫 칸만 일반 공백, 나머지와 블록 앞뒤는 `&nbsp;`"다 — Quill은 HTML을 읽을 때 일반 공백 연속을 접고 `getSemanticHTML()`은 모든 공백을 `&nbsp;`로 내보내므로 서버가 단일 원본으로 맞춘다(`docs/troubleshooting.md`). 첫 적용은 공지였고 지금은 공지 게시판을 포함한 모든 게시글이 같은 경로를 쓴다(`com.cms.admin.board`의 `CLAUDE.md`).
